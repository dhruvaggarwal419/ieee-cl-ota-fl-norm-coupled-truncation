# Norm-coupled truncation in over-the-air federated learning

Authors: Dhruv Aggarwal, Mohd. Rehan Ghazi, Ajay Kaushik.

`code/` simulation and learning code (`code/r3/` holds the federated learning experiments). `data/` saved results (JSON) for the assumption, imperfect-norm, convergence, bottleneck, causal-control and baseline studies.

Requirements: Python 3.11 with numpy, scipy, torch and matplotlib. Random seeds are fixed in the scripts. Large arrays are regenerated by the code and are not stored.
